# 🩺 ROBO-DOC – Healthcare Chatbot

ROBO-DOC is a **Healthcare Chatbot** that predicts possible diseases based on **patient symptoms** using machine learning techniques.  
It provides disease information, descriptions, and precautions through an interactive chat-based interface.

## 🚀 Features

- Symptom-based disease prediction
- Machine Learning–based diagnosis
- Interactive chatbot interface
- Disease description and precautions
- Clean and user-friendly UI
- Jupyter notebooks for research and experimentation

---

## 🛠️ Tech Stack

- **Language:** Python  
- **Machine Learning:** Scikit-learn  
- **NLP:** TF-IDF, text preprocessing  
- **Backend:** Flask  
- **Frontend:** HTML, CSS  
- **Notebooks:** Jupyter

## ▶️ How to Run the Project Locally

### 1️⃣ Clone the repository

git clone https://github.com/Pranav2100/Healthcare-Chatbot.git
cd Healthcare-Chatbot

2️⃣ Create and activate virtual environment
python -m venv venv
venv\Scripts\activate

3️⃣ Install dependencies
pip install -r requirements.txt

4️⃣ Run the application
python app.p
